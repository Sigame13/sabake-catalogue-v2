# Sabaké Catalogue v2

Catalogue officiel et interactif des **Éditions Sabaké** — Maison d'édition dédiée aux littératures africaines, romans, poésie, essais, jeunesse et culture.

## À propos du projet
Ce dépôt héberge le code source de l'application web du catalogue des Éditions Sabaké, permettant de consulter, rechercher et filtrer facilement les ouvrages publiés.
